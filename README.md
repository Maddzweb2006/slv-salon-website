# SLV Unisex Saloon & Academy — Pro Website

A polished, responsive static website using the actual salon photos supplied by the user.

## Included
- Real exterior photo as the full-bleed hero background with dark overlay for readable text
- Two real interior photos in an editorial gallery, plus exterior image
- Responsive desktop/mobile layout and mobile sticky call/directions bar
- Mobile navigation menu
- Click-to-call links (`tel:+916366255048`)
- Embedded Google Map and directions links
- Services, review highlight, academy section, address and contact
- No backend or build step required

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, or open the folder in VS Code.
3. Keep the `assets` folder beside `index.html`.

## Important before publishing for the business
- Verify the map pin, phone number, address and opening hours with the salon.
- Verify the rating/review count and obtain permission before using review quotes.
- Ask the owner to approve the photos and the final design.
- The service list is included, but no service prices are invented.
- All phone buttons use `tel:+916366255048`. On a phone this opens the dialler; desktop behavior depends on calling-app configuration.
- Google Maps links use the provided business name/address search and route destination; check the actual pin before going live.
- This is a static marketing website, so it does not need a backend. There is no online booking system or customer database.
- Use a hosting plan that permits commercial use. Vercel Hobby is intended for personal, non-commercial use; confirm the current terms and pricing for client hosting.
- Ideally, the salon owner should own the domain and hosting account and pay the provider directly.
